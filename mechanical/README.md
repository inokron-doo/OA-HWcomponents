# Mechanical

Enclosure and sensor-mount files for the SFS LoRa Sensor Network Node.

Contents:
- `SFS_Node_Enclosure_v0.1.stl` — Node enclosure (houses PCB + HLK-5M05 power module)

Printing: designed for FDM 3D printing

## Sensor mount (standard-pipe assembly)

The sensor nodes mount on standard construction pipe, clamped roughly 2 m
above the feeding trough with the distance sensors facing down. The design
was proposed by the pilot end-user farm and is deliberately low-tech: pipe
is robust to barn conditions, familiar on any farm, cheap, and fixable with
common parts — and node cabling can be routed through the pipe, away from
the animals.

There is no CAD model: the mount is assembled from off-the-shelf pipe and
clamp fittings, with the node enclosure clamped to the pipe and the height
and angle adjusted per trough.
