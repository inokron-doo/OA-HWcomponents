# Changelog

All notable changes to the SFS LoRa Sensor Network Node hardware are documented
in this file. Hardware versions are also tracked by PCB silkscreen marking and
repository tags.

## [v0.1] - 2026-06-17

Initial public release under the OpenAgri EU project (SIP13).

### Included
- Schematic export (PDF)
- PCB fabrication outputs (Gerber, drill, reports — Altium)
- Hardware documentation (docx)
- Starter Bill of Materials (CSV, in progress)
- CERN-OHL-S v2.0 licence

### Pending (future release)
- Schematic and PCB **source files** (Altium project) — after June 2026
- Enclosure / mount STL files
- Completed Bill of Materials with full manufacturer part numbers

### Notes
- Field-validated at Novak farm, Kranj, Slovenia (4 sensor nodes, 1 concentrator).
